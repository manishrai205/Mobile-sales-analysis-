# Mobile-sales-analysis
📱 Mobile Sales Analysis Dashboard — Power BI

An interactive Power BI Mobile Sales Analysis Dashboard designed to transform raw mobile sales data into meaningful business insights. The dashboard provides a comprehensive view of sales performance, transaction trends, customer behavior, product performance, and payment preferences through interactive visualizations and dynamic filters.

📊 Project Overview

This project focuses on analyzing mobile sales data to understand how products, brands, locations, customer demographics, payment methods, ratings, and time periods influence overall sales performance.

The dashboard allows users to interact with the data using slicers and explore different aspects of the business dynamically.

🎯 Key Objectives
